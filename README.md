# UE.Toolkit.GeneratedClasses

Generated classes and structs using [UE Toolkit](github.com/RyoTune/UE.Toolkit). This allows for mod developers using Reloaded-II to utilise the game's data types in C#, including read/write operations on structs and classes or calling methods from a target UObject. Packages are published onto NuGet.

## Generated Types Available

- **Life is Strange: Double Exposure** (`UE.Toolkit.ChronosTypes`): Unreal Engine 5.2
- **Persona 3 Reload** (`UE.Toolkit.P3RTypes`): Unreal Engine 4.27
- **Shin Megami Tensei V: Vengeance** (`UE.Toolkit.SMT5VTypes`): Unreal Engine 4.27
